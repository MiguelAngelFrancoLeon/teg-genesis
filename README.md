## Cómo publicarlo (solo la web de GitHub, sin terminal)

1. Entrá a [github.com/new](https://github.com/new).
2. Repository name: `teg-genesis`. Public. Create repository.
3. En la pantalla vacía, elegí **uploading an existing file**.
4. Arrastrá **todos** los archivos de este paquete (`index.html`, `assets/`, `favicon.svg`, `.nojekyll`).
5. Commit changes.
6. **Settings → Pages**.
7. Source: **Deploy from a branch**.
8. Branch: `main`, folder: `/ (root)`. Save.
9. Esperá un minuto y abrí la URL de Pages (la muestra esa misma pantalla).

Importante: GitHub Pages sirve archivos estáticos. Esta carpeta ya está compilada. No subas el proyecto completo de Node; subí este paquete.

El preview de Grok sigue siendo la versión en vivo para iterar. GitHub Pages es la copia pública permanente.
